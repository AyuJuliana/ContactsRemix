# 📱 ContactsRemix

ContactsRemix is an iOS application project built with **Swift and Xcode**, focusing on implementing a contacts-based mobile application.

## 🛠️ Tech Stack

* Swift
* Xcode
* iOS

## ✨ Features
- Manage and display contacts
- Search and browse contacts
- iOS-native user interface
- Built with Swift and Xcode
- Add and deleted contact
- Grouping the contacts
- Relationship between yourself with your contact 

## 🚀 Getting Started

1. Clone this repository:

```bash
git clone https://github.com/AyuJuliana/ContactsRemix.git
```

2. Open the project in **Xcode**.
3. Select an iOS simulator or connected device.
4. Build and run the application.
